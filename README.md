# KarimDM

مدير تحميل مجاني معمول لكريم، بواجهة Desktop داكنة وبدون إعلانات أو حساب.

## التشغيل على Windows

من صفحة Releases حمّل `KarimDM-1.0.0-Windows-x64.exe` وشغله. نسخة Portable، مش محتاجة Node.js ولا Python على جهازك. محتاج Windows 10/11 بنظام 64-bit.

- اضغط **Add download** وحط لينك مباشر HTTP أو HTTPS.
- اختار **Browse** عشان تحدد مكان الحفظ، وبعدها **Start download**.
- تقدر تلزق اللينك في النافذة أو تسحبه ليها.
- زر **Pause** بيحفظ الأجزاء. بعد فتح البرنامج تاني اضغط **Resume**.
- **Download settings** بتحدد عدد التحميلات مع بعض وعدد الاتصالات للملف.
- بعد الانتهاء استخدم **Open file** أو **Show in folder**.
- إزالة التحميل المكتمل من القائمة مش بتمسح الملف النهائي.

## اللي بيشتغل

تحميل متوازي لحد 8 اتصالات للملف لو السيرفر بيدعم Byte Ranges، قائمة تحميلات، حد للتحميلات المتزامنة، السرعة والتقدم والوقت التقريبي، اختيار مجلد، وحفظ الحالة بعد قفل البرنامج. الملفات الموجودة مش بيتم استبدالها، بيتضاف رقم للاسم.

## حدود النسخة الأولى

- ده برنامج مستقل، مش نسخة IDM ومش تابع له. مفيش إضافة متصفح أو التقاط تلقائي للفيديو.
- الروابط لازم تكون مباشرة. صفحات YouTube وملفات DRM وروابط محتاجة تسجيل دخول أو cookies مش مدعومة.
- الاستكمال الحقيقي محتاج السيرفر يدعم Range والملف يكون ثابت وليه ETag قوي أو Last-Modified. غير كده التحميل بيبدأ من الأول بأمان بدل خلط بيانات قديمة بجديدة.
- زيادة الاتصالات مش ضمان لزيادة السرعة. سرعة النت وحدود السيرفر هي اللي بتحكم.
- البرنامج غير موقّع بشهادة Code Signing. Windows ممكن يعرض تحذير ناشر غير معروف. قارن SHA-256 بملف `SHA256SUMS.txt` واتأكد من المصدر. متوقفش الحماية عشان تشغله.
- مش بيفحص الملفات ضد الفيروسات. حمل من مصادر موثوقة وافحص الملفات قبل فتحها.
- بيحفظ روابط التحميل وأسماء الملفات وملفات الأجزاء محليا في بيانات التطبيق. الروابط المؤقتة ممكن تحتوي بيانات حساسة، متشاركش مجلد بيانات التطبيق.
- النسخة Portable تحتفظ بالطابور في بيانات حساب Windows، مش جنب ملف البرنامج.

## للمطور

Node.js 22 أو أحدث:

```text
npm ci
npm start
npm test
npm run test:ui
npm run dist:win
```

البناء الرسمي على Windows بيتحقق من فتح الواجهة، تحميل متوازي، إيقاف واستكمال بعد خروج وفتح كامل للتطبيق، وتطابق SHA-256. كمان بيشغل الـEXE النهائي في اختبار مستقل قبل نشره.

الكود MIT. مفيش Analytics أو سيرفرات وسيطة للتحميل. البرنامج بيتصل بسيرفر اللينك اللي بتضيفه.
